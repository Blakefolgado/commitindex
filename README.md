# Commit Index

Explore public GitHub activity across popular startups and large technology
companies.

Live at [commitindex.com](https://commitindex.com).

## What the grid measures

Each company calendar sums GitHub's official daily commit statistics across the
organisation's eight most recently active public, non-fork, non-archived
repositories.

The grid:

- excludes merge commits because GitHub's repository statistics exclude them;
- excludes private and internal repositories;
- covers GitHub's rolling 52-week statistics window;
- serves checked-in server snapshots generated by the offline ingestion job;
- marks dates outside the available window as unavailable rather than zero.

It is a view of public open-source activity, not a measure of company size or
employee productivity.

## Deep dives

- `/company/[org]` adds shipping patterns, repository pulse and contributor
  rankings aggregated across the same repository sample.
- `/leaderboards` ranks the curated directory by commits, consistency,
  momentum, active days and weekend activity for companies and 2,371 public
  contributors.
- `/compare` compares up to three organisations using stored snapshot data.
- `/compare/people` compares individual public contributor activity, additions
  and deletions.
- Company pages render a custom 1200×630 Open Graph image from the same data.

V1 ships 85 fully indexed companies. A larger verified catalogue is checked in
and only becomes visible as its guarded snapshots are generated, preventing
empty rows or incomplete comparisons.

Every visitor-facing page and public API reads checked-in snapshots. Browsing,
searching, comparing and generating company metadata never calls the GitHub
API. GitHub access is isolated behind an authenticated ingestion endpoint used
only by the offline generators.

Start the ingestion server with a private secret, then refresh all snapshots:

```bash
GITHUB_TOKEN=github_token COMMIT_INDEX_INGEST_SECRET=local_secret pnpm dev
COMMIT_INDEX_INGEST_SECRET=local_secret pnpm organizations:generate
COMMIT_INDEX_INGEST_SECRET=local_secret pnpm leaderboard:generate
COMMIT_INDEX_INGEST_SECRET=local_secret pnpm people:generate
```

When adding companies, reuse verified rows and fetch new organisations in
guarded batches:

```bash
COMMIT_INDEX_INCREMENTAL=1 COMMIT_INDEX_BATCH_SIZE=10 COMMIT_INDEX_INGEST_SECRET=local_secret pnpm organizations:generate
OPEN_OFFICE_INCREMENTAL=1 OPEN_OFFICE_BATCH_SIZE=10 OPEN_OFFICE_WORKERS=1 COMMIT_INDEX_INGEST_SECRET=local_secret pnpm leaderboard:generate
OPEN_OFFICE_INCREMENTAL=1 OPEN_OFFICE_BATCH_SIZE=10 OPEN_OFFICE_WORKERS=1 COMMIT_INDEX_INGEST_SECRET=local_secret pnpm people:generate
```

The generators refuse to overwrite snapshots if any requested company fails,
so rate limits cannot silently publish a partial directory.

The UI displays the snapshot's real generation date. A zero GitHub statistics
response is shown as unavailable data, not as proof that a company shipped
nothing.

## Local development

```bash
pnpm install
pnpm dev
```

Normal development and visitor traffic do not require a GitHub token.
